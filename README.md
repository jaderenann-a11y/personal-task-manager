# Personal Task Manager

A simple Personal Task Manager built using Laravel. This project allows users to create, view, edit, delete, and update the status of tasks.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
- Set Due Date
- Task Description

## Task Fields

Each task contains:

- Task Name
- Description
- Status (Pending or Completed)
- Due Date

## Project Structure

The project follows the Laravel structure:

**Routes → Controller → Model → Database → Blade Views**

## How It Works

The user interacts with the Blade views. The routes send requests to the Task Controller. The Controller uses the Task Model to communicate with the SQLite database. The stored task information is then displayed through the Blade views.
